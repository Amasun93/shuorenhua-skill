# “说人话”Skill 的理论底座

这份参考只在调整 Skill、设计新模式或复盘解释失败时阅读。正常回答不需要向用户展示理论名称，也不需要把解释写成教学论文。

## 1. 认知负荷理论：先减掉不必要的难度

认知负荷理论关注学习材料的复杂度、呈现方式和学习者已有知识如何共同影响理解。对“说人话”最有用的启发是：专业内容本身可能已经很难，不要再用糟糕的组织、过多术语和无关细节增加额外负担。

转成 Skill 规则：

- 先给一个总的生活场景，再拆术语；
- 一组相关词放进同一个场景，不要让读者在多个比喻之间来回切换；
- 按需展开，用户只问一个词时不要自动讲完整学科；
- 把真正不可省略的复杂度保留下来，把装饰、重复和旁枝删掉。

主要来源：[Sweller, Cognitive load during problem solving: Effects on learning](https://doi.org/10.1016/0364-0213(88)90023-7)。

## 2. 结构映射理论：类比要对齐关系

结构映射理论认为，好的类比主要不是因为两个东西“长得像”，而是因为它们之间的关系、动作或因果结构可以对齐。例如，店铺和云平台外表完全不同，但“店铺需要物业、物业提供资源并设置限制”这组关系可以帮助理解云平台。

转成 Skill 规则：

- 优先映射“谁服务谁、谁限制谁、谁调用谁、结果如何产生”；
- 不把生活对象的无关属性带进专业概念；
- 解释一组术语时，优先保持关系网络，而不是为每个词单独找一个漂亮比喻；
- 类比无法继续承载某个关系时，换场景或补充专业定义。

主要来源：[Gentner, Structure-Mapping: A Theoretical Framework for Analogy](https://doi.org/10.1207/s15516709cog0702_3)。

## 3. 支架式教学：帮助读者走完下一步

支架式教学把讲解看成一种有针对性的支持：读者暂时做不到的部分，讲解先替他搭一个支撑；等他建立起基本结构后，再把支撑撤掉，让他自己使用专业词和关系。

转成 Skill 规则：

- 对完全陌生的概念，先给生活故事，不要求读者先掌握术语；
- 对已经懂一部分的读者，减少铺垫，直接补缺口；
- 用“生活场景 → 术语对应 → 实际案例 → 用户自己判断”的顺序逐步过渡；
- 用户追问时再增加深度，不在第一轮把所有细节一次讲完。

主要来源：[Wood, Bruner & Ross, The Role of Tutoring in Problem Solving](https://pubmed.ncbi.nlm.nih.gov/932126/)。

## 4. 多媒体学习理论：让文字和画面各做一部分工作

多媒体学习理论强调，人会通过不同的信息通道处理文字和图像，但每个通道的处理能力都有限，学习需要主动选择、组织并把新信息和已有知识连接起来。

“说人话”不一定要生成图片，也可以用文字制造清晰的心理画面，再用表格把关系固定下来：生活故事负责让人看见场景，表格负责让人看清对应关系，简短定义负责校准含义。

转成 Skill 规则：

- 用动作和关系制造画面，不堆无关形容词；
- 表格只保留帮助比较和记忆的列；
- 生活故事、术语表和正式定义要互相补充，不能重复说同一件事；
- 不要用过多 emoji、装饰性格式或长段背景抢占注意力。

主要来源：[Mayer, Cognitive Theory of Multimedia Learning](https://www.cambridge.org/core/books/abs/cambridge-handbook-of-multimedia-learning/cognitive-theory-of-multimedia-learning/3A0E495CDB9D9D84665FAEFCBAB51D05)。

## 5. 受众设计与编码—解码：同一句话不一定被同样理解

受众设计提醒我们，表达方式会随着听众变化。编码—解码视角进一步提醒：发送者认为已经说清楚的内容，接收者可能用另一套背景知识去理解。

转成 Skill 规则：

- 默认面对没有该领域背景的读者，不把“听不懂”归因于读者能力；
- 根据用户的目标调整深度：入门、比较、操作和排错不是同一种解释；
- 同一个术语可以换不同生活场景，但要保持专业关系不变；
- 当用户反馈“这个比喻好”或“还是不直观”时，调整场景和解释路径，而不是只换几个词。

主要来源：[Bell, Language Style as Audience Design](https://web.stanford.edu/~eckert/PDF/bell1984.pdf)；[Hall, Encoding and Decoding in the Television Discourse](https://epapers.bham.ac.uk/2962/)。

## 设计上的总合

这些理论最后汇成一条实践原则：

> 先降低无关难度，再用一个关系准确的生活场景搭桥；根据读者当前的理解程度逐步撤掉支撑，并用表格和简短定义把专业关系固定下来。
